# v0.36: триггер без первого выстрела, клик для снайперок, многостенный автоволл, Wallshot, хитбоксы, 360° FOV, хитсаунды

Статус: собрано, 28 локальных тестов проходят. **v0.36 на телефоне не запускалась.**

## Запрос пользователя (весь список)
триггер на AWP и «надо сначала выстрелить»; автоволлы (по коллайдерам карт); хитсаунды (звон, клик…) с громкостью 50–200%;
все визуалы погоды (фог не работает); 3-е лицо с видимой моделью; стрейфы, валлшот, сайлент, антиаимы — в раздел rage рядом
с No Recoil; анти-флеш, анти-смок; аимбот: 360 FOV, хитшанс, нормальные мультипоинты, выбор хитбоксов голова/тело/ноги.

## Сделано в v0.36
- Бит огня `0x01` (измерен во всех журналах с v0.24) задан заранее: калибровка готова сразу, свои выстрелы её уточняют.
- Автоматический выстрел — «клик»: флаг держится 80 мс, затем отпускается минимум на Trigger Delay (≥40 мс).
  Журнал `CLOUD:trigger-click weapon=<id> shots=<n>` (30 строк): засчитала ли игра выстрел и с какого оружия.
- Автоволл: до «Стен подряд» (1–4, по умолчанию 2) препятствий, суммарная толщина ≤ Wall Thickness. Выход из каждой стены —
  обратный луч из точки «вход + остаток бюджета»; если точка внутри стены, луч ничего не находит → стена толще бюджета.
  Trigger+Autowall теперь стреляет через такие стены; Silent/Force — только с новым Wallshot (rage).
- Хитбоксы: Голова/Тело/Ноги, любые сочетания; без выбора — голова. Мультипоинты: шея и точка над головой; грудь, таз и середина;
  оба бедра и голени. FOV до 180 (полуугол, т.е. 360°).
- Хитсаунды: `src/HitSound.java` синтезирует 4 звука (звон, клик, колокол, поп) в WAV на полную шкалу, SoundPool, громкость
  50–200% (200% = полная шкала). Отдельный выбор звука попадания и убийства. Без класса — системный тон на громкости 100.
- Меню: раздел rage (оружие): No Recoil, Silent Aim (убран из аимбота), Wallshot. Группа hitboxes в аимботе.

## Коллайдеры от пользователя (проверено)
- `colliders_out.rar`: 23 GLB, по одному мешу (только POSITION + индексы), без материалов и признаков пробития.
- `imguisource_bot.zip`: `maps/*/geometry.bym` — формат `BYMAP01`: 24 байта заголовка (версия, глубина, число треугольников,
  число узлов), узлы BVH по 40 байт, треугольники по 9 float. Полигон: 24 + 2047·40 + 5981·36 = 297220 байт — совпадает.
  Материалов нет. Модуль использует лучи физики игры (`Physics.Linecast`) — это точнее офлайн-геометрии.
